# AWS APAC Solutions Architecture Project

## Scalable Hosting Architecture

This project demonstrates the design of a scalable cloud hosting architecture using Amazon Web Services.

## Project Objective

Redesign a single-server application architecture to improve:

- Scalability
- Availability
- Performance
- Reliability
- Operational efficiency

## Architecture

The proposed architecture uses:

- Amazon Route 53
- Application Load Balancer
- AWS Elastic Beanstalk
- Amazon EC2
- Auto Scaling
- Amazon RDS
- Amazon S3
- Amazon CloudWatch

## Application

The project includes a Flask web application that displays the proposed AWS architecture and provides application health endpoints.
